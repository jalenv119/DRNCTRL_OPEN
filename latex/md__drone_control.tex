{\ttfamily Tello\+Driver} is an asyncio {\ttfamily Datagram\+Protocol} that:\+


\begin{DoxyItemize}
\item Opens a UDP socket bound locally (default port {\ttfamily 9000})
\item Sends plain-\/text commands to the drone (e.\+g. {\ttfamily "{}command"{}}, {\ttfamily "{}takeoff"{}}, {\ttfamily "{}land"{}})
\item Waits for a response from the drone and returns it (or {\ttfamily "{}TIMEOUT"{}} on no reply)
\end{DoxyItemize}

{\bfseries{Key methods:\+}}
\begin{DoxyItemize}
\item {\ttfamily create\+\_\+drone(ip, drone\+\_\+port)} — creates the driver, binds local socket, and sends {\ttfamily "{}command"{}} to initialize SDK mode.
\item {\ttfamily run\+\_\+command(command, timeout=7)} — sends a command and waits for the drone response.
\item {\ttfamily close()} — closes the UDP connection cleanly.
\end{DoxyItemize}\hypertarget{md__drone_control_autotoc_md2}{}\doxysubsection{\texorpdfstring{Example control flow + error handling ({\ttfamily drone.\+py})}{Example control flow + error handling ({\ttfamily drone.\+py})}}\label{md__drone_control_autotoc_md2}
The example script uses {\ttfamily try/\+except/\+finally} to ensure the drone is commanded to land and the connection is cleaned up even if an error occurs. Note that {\ttfamily "{}land"{}} will error if the drone is not flying, so it’s wrapped in the {\ttfamily finally} block as a best-\/effort safe shutdown.
